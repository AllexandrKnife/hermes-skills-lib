## Модель ВСУ: «принуждение через экономический каскад»
(coercive economic cascade)

- Стратегия: coercive bargaining — официально объявленное «принуждение
  России к миру» (40-дневная операция, утверждена 25.06.2026; Буданов
  03.08: продолжение «бессрочно»). Малюк (24.04.2026): «асимметричные
  удары» — метод назван самими.
- Оператика: economic cascade — цели ранжируются по каскадному ущербу
  (топливо → экспорт/флот → логистика/финансы); повторные удары по
  перезапускам = «удержание в выведенном состоянии».
- Тактика: counterforce как УСЛОВИЕ (ПВО-ослепление, аэродромы носителей).
- Триггеры: tit-for-tat на удары по городам (задержка 2–5 суток);
  усиление ударов накануне переговорных раундов (прецедент «Паутины»
  01.06.2025 перед Стамбулом 02.06.2025).
- Ограничитель: capability (FP-1 3400 км) + заброска («Паутина»:
  117 дронов, 4 авиабазы — Оленья/Белая/Дягилево/Иваново-Северный,
  12 самолётов уничтожено, 10 подбито; метод — контейнеры/бытовки
  на фурах внутри РФ).

## Модель ВС РФ: «удушение и деморализация» (attrition of resilience)

- Стратегия: системные удары по гражданской инфраструктуре — энергетика
  (2/3 генерации, 4 волны DiXi 2022–2026), города, бытовая цепочка
  (АЗС «на потоке», «Нова пошта», склады Rozetka/Эпицентр). Обвязка
  НЕ «принуждение к переговорам», а официально «демилитаризация»
  + риторика возмездия («ответ за Геленджик, за НПЗ, за Wildberries»).
- Оператика: энергетический каскад + логистическое удушение (мост
  в Затоке «Искандер-М» 02.08, сухогрузы, порты; мосты через Днепр —
  НЕ паттерн, см. why-not-bridges).
- Тактика: истощение ПВО баллистикой (0 из 28 перехвачено 05.08;
  ЗУР С-300/400 как баллистика; Ставридис: 27 ракет на 1 перехватчик)
  + дроновые волны 600+/сутки (Shahed-238 — неограниченный ресурс).
- Триггеры: возмездие (1–3 суток) + цикл накопление → массированная волна.
- Ограничитель: производственные потолки ракет (9М723 ~90/мес +
  48Н6ДМ ~50/мес ≈ 140–150; Х-101 50–60; Калибр ~40; ISW 20.07:
  июль тратил резервы).

## Ключевые различия (для скрещивания моделей)

1. Асимметрия затрат обратная: РФ — дорогие ракеты (~$1–5 млн [оценка])
   по дешёвым целям (ограничено производством); ВСУ — дешёвые дроны
   по дорогим целям (масштабируемо).
2. Политическая обвязка: ВСУ — переговорный рычаг; ВС РФ — возмездие
   + внутренняя демонстрация «победы» (Левада фев 2026: 2/3 россиян
   за переговоры — внутренняя цена растёт, гасится информационным
   контролем).
3. Деморализация ВС РФ провалилась (консолидация Украины), но модель
   продолжает работать по инерции и внутренней выгоде.
4. Симметрия итога: обе стороны — «обмен инфраструктурными целями»
   (НПЗ/флот ↔ энергетика/доставка); обе считают обмен приемлемым —
   «цена удара по городу» для обеих пока не запретительна.

## Рамка «цены удара по городу» (трёхуровневая, tit-for-tat)

Tit-for-tat = сигнальный механизм (не месть): ответ немедленный,
зеркальный по типу цели, пропорциональный — противник должен считать
причинно-следственную связь. Три уровня цены:
- А. Материальная (тактическая): стоимость восстановления/ВВП/ПВО;
  ответ должен стоить противнику ≥ X, иначе бить выгодно.
- Б. Социально-политическая (внутренняя): жертвы консолидируют или
  деморализуют; ответ компенсирует унижение своей аудитории.
- В. Сигнальная (внешняя, самая важная): цена потери переговорной
  позиции. Нет ответа → «ресурсы кончаются» → бьют чаще. Есть ответ →
  «гарантированный неприемлемый ущерб» → политическая ценность удара
  падает до нуля. Итог: политический смысл удара по городу есть только
  пока противник НЕ готов ответить тем же; ответ лишает инициатора
  эксклюзивного права на эскалацию.

## Прогнозные якоря на 05.08.2026 (см. также 2026-08-05-verified-data.md)

- ВСУ: 60–80% ответ на Киев-05.08 в 2–5 суток; >60% морская линия +
  ПВО-ослепление; 50–70% удержание топливного сектора; 40–60% НПЗ
  в сентябрьском окне (~0,98 млн т); 30–50% балтийская линия; <30%
  «Паутина-2» (Белая/Украинка/Ангарск), <30% системные удары по Москве.
- ВС РФ: >60% удушение (энергетика + логистика + бытовая цепочка,
  подготовка к зиме 2026–27); >60% истощение ПВО баллистикой по Киеву;
  50–70% дроновые волны 600+/сутки; 40–60% дегазификация к сентябрю;
  <30% отказ от гражданских целей.
- Контр-индикаторы обеих моделей: смена привязки ударов к переговорам
  (у ВСУ) / пауза баллистики >2 недель и падение дроновых волн <300
  (у ВС РФ) / удары по мостам через Днепр (эскалация).
