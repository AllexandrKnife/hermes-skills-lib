# Топливный баланс Татарстана: мощности и потребление бензина (08.2026)

Собрано 11.08.2026 (кейс: удар по ТАНЕКО 10.08.2026). Для расчётов
«что осталось в регионе» и месячных балансов.

Итого до удара: ~3,3 млн т/год товарного бензина (ТАНЕКО 2,7 +
ТАИФ-НК ~0,5 + ЕНПЗ ~0,07). После вывода ТАНЕКО: ~0,6 млн т/год.

Внимание: производство региона ≠ потребление региона. ТАНЕКО
снабжал сеть АЗС Татнефти по всей РФ (на М-5 после Саратова
«на АЗС Татнефти нет бензина» уже с 02.08) — выпадение 2,7 млн т/год
бензина + 8,5 млн т/год дизеля бьёт по общероссийскому предложению,
а не только по РТ.

## Месячный баланс (рабочие цифры 11.08.2026)

- Потребление РТ: ~100 тыс. т/мес [оценка, диапазон 85–125].
- Остаток мощностей после вывода ТАНЕКО: ТАИФ-НК ~42 тыс. т/мес +
  ЕНПЗ ~6 тыс. т/мес = ~48 тыс. т/мес.
- Дефицит собственного производства: ~52 тыс. т/мес (~50%
  потребления) — покрывается только завозом (Самара/Уфа/Пермь/
  Н.Новгород).
- Выпавший объём ТАНЕКО из РФ-предложения: ~225 тыс. т/мес бензина
  + ~708 тыс. т/мес дизеля.

## Метод оценки потребления региона (когда нет региональной статистики)

Прямых данных Росстата по бензину РТ в открытом доступе нет —
оценка двумя независимыми методами, фиксировать диапазон:

1. Якорь по соседнему региону: Удмуртия (TASS, 11.08.2026) —
   суточное потребление ~850 т при населении ~1,45 млн.
   Масштаб: (население РТ ~4,0 млн / 1,45 млн) × 850 т ≈ 2345 т/сут;
   поправка 1,15–1,3 на повышенную автомобилизацию/транзит
   (Казань, М-7/М-12, Челны) → ~2800 т/сут ≈ 84 тыс. т/мес.
2. РФ-баланс: потребление бензина РФ ~39 млн т/год, автопарк
   ~50 млн легковых (АВТОСТАТ: 331 легковой/1000 чел.); РТ ~1,4 млн
   легковых → доля 2,8% × 39 млн т ≈ 1,1 млн т/год (+10% коммерческий/
   транзит) ≈ 100 тыс. т/мес.

Итог: рабочая оценка 100 тыс. т/мес, диапазон 85–125 тыс. т/мес
[оценка, НЕ статистика].

Контекст дефицита РТ: середина июля 2026 — суточные объёмы на
казанских АЗС раскупались за 6 часов, частные АЗС до 120–130 руб/л
(АиФ Казань); Казань 76% АЗС с топливом (189/248) — см.
fuel-crisis-regional-status-aug2026.md.

## Полный реестр переработки РТ (проверено 11.08.2026 по 4 реестрам + ЕГРЮЛ)

Производители товарного бензина — только 3 завода (таблица выше).
Полный состав переработки региона:
- ТАНЕКО: первичка 15,96 млн т/год, Нельсон 12,3; FCC 1,1 млн т/год,
  гидрокрекинг 4,5, УЗК 2,4 (energybase).
- ТАИФ-НК: первичка 8,30 млн т/год (7,3 нефть + 1,0 конденсат; уточнение
  по energybase, Wikipedia даёт 7,3+1,0 — согласуется), Нельсон 12,49
  (ВЫШЕ ТАНЕКО!), каталитический крекинг 1,0, КГПТО/VCC (глубина до 95%).
- Елховский НПЗ: 0,49 млн т/год (введён 1995, блок стабилизации 2001).
- Миннибаевский ГПЗ (Татнефтегазпереработка, Нижняя Мактама): ПНГ
  >3 млрд м3/год → ШФЛУ/сухой газ/газовый бензин (компонент, НЕ товарный АИ).
- НКНХ (СИБУР): этилен 650 тыс. т, пропилен 220 тыс. т/год — не бензин.
- Казаньоргсинтез (СИБУР): этилен 652, пропилен 60 тыс. т/год — не бензин.
- «Аммоний» (Менделеевск): аммиак 717,5 / карбамид 758,8 тыс. т/год — не бензин.

Мини-НПЗ с товарным бензином в РТ: НЕ обнаружены. Метод проверки:
pronpz «Список мини-НПЗ» (Славянский, Ильский, Каменский, Волгодонский,
Целинский, Новошахтинский, Техносити — без РТ) + energybase/uglevodorody
по региону + реестр Минэнерго (86 НПЗ, tek-all) + ЕГРЮЛ по ОКВЭД 19.20.
Контекст: в РФ ~250 мини-НПЗ (глубина ~40%), но новые без глубины >=70%
не подключаются к магистральным нефтепроводам — действующих с товарным
бензином в РТ нет.

Кейс «Карабаш» (Бугульминский р-н, 11.08.2026): пользователь указал на
«заводик в Карабаше» — по реестрам это НПС «Карабаш» (Транснефть,
насосная станция, нефтепровод Карабаш–Альметьевск–Калейкино) и
ООО «БНК-Трейдинг» (трейдер топлива, ИНН 1645015240). НПЗ там нет.
Правило: при указании пользователя на объект, которого нет в реестрах —
проверять ЕГРЮЛ/региональные источники, при отсутствии честно сказать
и запросить название/ИНН (ask-first), не выдумывать.
