# Калибровка моделей после сверки прогнозов (метод 10.08.2026)

Источник: сверка прогнозов 02/05/08.08.2026 с фактами 08–10.08
(Корреляция_прогнозов_2026-08-10.txt, Правки_моделей_после_сверки_2026-08-10.txt
в /root/Россия-Украина/). 4 промаха = 4 дефекта модели, не ошибки данных.
Применять к ЛЮБОМУ прогнозу векторов сторон.

## Промахи и правки

| Промах | Дефект модели | Правка |
|--------|---------------|--------|
| ТАНЕКО (Татарстан) не предсказан | выбор целей по «западности», без реестра ударов | реестр ударов как вход; цель 2+ раз/60 дней = приоритет повторного удара |
| Одесская ТЭЦ + 7×330 кВ (10.08) | энергоудары смоделированы сезонно (октябрь) | «энергетика следует за логистикой» региона-хаба |
| Баллистика сместилась с Киева на Одессу | столица как главная цель | цели = точки сборки (порт/энергоузел/ж-д узел); «0 из N» — метрика ПВО, не цель |
| Волны дронов 828–970 vs прогноз 1000–1200 | монотонный рост вместо цикла | цикл накопление→пик→спад 15–30%→пик через 1–3 нед |

## 6 правил калибровки (кратко)

1. **Реестр ударов обязателен**: дата, цель, тип (npz-tactical-map.vercel.app —
   карта ударов по НПЗ с датами; Wikipedia «Инциденты»). 2+ удара за 60 дней
   = приоритет повторного удара (ТАНЕКО: 12.06, 16.06, 08.07, 10.07 + 10.08).
2. **География по досягаемости**: FP-1 до 3400 км; любой НПЗ >10 млн т/год
   в радиусе — кандидат, независимо от региона. Не «западные» vs «восточные».
3. **Точки сборки**: удары прогнозировать по регионам-узлам (порт/КПП/ж-д/
   энергоузел). Логистический удар по хабу → энергоудар по региону в 1–7 суток.
4. **Циклы вместо сезонов**: волны дронов = накопление→пик→спад; энергетика
   идёт круглый год, зимой пики. Сезонные рамки — только для оценки пиковости.
5. **Скользящее окно 7–14 дней** для вероятностных рамок; потолок волны =
   фактический пик серии (1158 за 02.08), не «ожидание роста».
6. **Частичное подтверждение отдельно**: при сверке считать 4 категории
   (подтверждено/частично/нет/нет данных). Частичное = направление поймано,
   цель не угадана — это полезный сигнал, не провал.

## Ожидаемый эффект
Стратегическая точность ~90% сохраняется; тактическая (конкретные цели)
растёт с ~40–50% до 60–70%; тайминг tit-for-tat 2–5 суток — уже точный.
Ограничение: модель предсказывает вероятностные категории, не конкретный
удар (выбор цели зависит от разведки сторон).
