# Construction Estimate Fraud Analysis (Анализ смет на фрод)

## When to Use

Use this skill when the user asks to review a construction estimate (смета) for overpricing, inflated volumes, or fraud indicators. Typical triggers: "проверь смету", "найди завышения", "есть ли фрод", "проанализируй договор подряда".

## Workflow

### 1. Проверка арифметики
Первым делом — проверить сложение. Сложить колонки работ и материалов, убедиться что НДС посчитан верно.

### 2. Классификация нарушений по степени риска
- **КРИТИЧЕСКАЯ**: завышение объёмов >50%, цены x2+, отсутствие товара в принципе
- **ВЫСОКАЯ**: завышение работы/материалов на 30-100%, подмена премиум-бренда бюджетным
- **СРЕДНЯЯ**: завышение на 15-30%, сомнительная маржа
- **НИЗКАЯ**: до 15%, может быть объяснено коммерческим статусом

### 3. Поиск рыночных цен — приоритет источников

**Для РФ (работающие источники):**
1. Stroylandiya — stroylandiya.ru (искать по search/?q=...). Если JS-рендеринг блокирует товары — извлекать **price slider** из HTML: `data-min="X" data-max="Y"`. Когда min=max — это точная цена. Также искать `найдено N товаров` для оценки ассортимента.
2. Avito (Саратов/регион) — avito.ru/город/predlozheniya_uslug. Первый запрос обычно проходит, потом IP может быть rate-limited. Использовать с умом.
3. Lemana Pro (Саратов) — saratov.lemanapro.ru. За Qrator-защитой — открывается только с российских IP. Если доступен — прямой поиск по каталогу и товарам.
4. EGGER Russia — egger-russia.ru. Только каталог декоров, розничных цен нет. Нужен для идентификации: EGGER H1145 ST10 = decor code, not a finished product.
5. tdserver.ru, list-plit.ru, planetadsp.ru — дистрибьюторы ЛДСП/плитных материалов.

**При блокировке** (captcha, 403, Qrator, geo-block):
- Сменить User-Agent на Yandex Browser + `Accept-Language: ru-RU,ru;q=0.9`
- Попробовать региональный поддомен (saratov.site.ru)
- Извлечь partial data из того что загрузилось (price-slider, JSON-LD, заголовки)
- Минимум 3 попытки разными подходами перед признанием «нет данных»

### 4. Структура отчёта (docx)

```
0. Методология и ограничения
   - Какие источники работают/не работают
   - Ограничения (инфляция, коммерческий статус, дата сметы vs дата анализа)

1. Проверка арифметики

2. Анализ позиций (каждая позиция отдельно)
   - Таблица: Смета vs Подтверждённый рынок vs Оценка
   - Расчёт объёмов (СНиП, коэффициенты разрыхления)
   - Ссылки на источники (кликабельные hyperlinks в docx)
   - Оценка завышения в рублях + степень риска

3. Сводная ведомость
   - Разделить: подтверждённые прямыми ссылками vs экспертная оценка
   - Общий итог в рублях и % от сметы

4. Слабые места анализа / контраргументы подрядчика
   - Коммерческий статус объекта
   - Дилерские vs розничные цены
   - Полный цикл работ vs отдельные операции
   - Инфляционный разрыв

5. Рекомендации
   - Какие документы запросить у подрядчика
   - Какие замеры сделать на объекте
```

### 5. Ключевые признаки фрода

| Признак | Что смотреть |
|---------|-------------|
| «Премиум-бренд» без модели | EGGER H1145 ST10 = decor code, not a door. Grohe без модели = может быть Eurosmart за 5 000 |
| Объём мусора | Стяжка 50мм: 415м2 x 0,05м x 1,6(коэфф) = 33м3. + упаковка ~5-10м3. Всё что сверх — завышение |
| Двойная оплата | Две грунтовки под разные этапы — это нормально. Одна и та же работа дважды — нет |
| Ставка НДС | Если ставка 22% — проверить нормативный документ. Если 20% — переплата |
| Такелаж | Грузчики 350-600 руб/час. Такелажники с разборкой: 600-900 руб/час. Выше — завышение |

## SC W-1 Penalty Arsenal (Beeline contracts)

When analyzing contracts under Beeline/ВымпелКом SC/GC framework:

**П. 8.1 SC W-1:** Неустойка 0.2-0.4%/день за просрочку работ.
- ≤14 дн → 0.2%/день
- 14-30 дн → 0.3%/день  
- >30 дн → **0.4%/день** (за весь период с первого дня)
- База: стоимость работ (не материалов)

**Дополнительные рычаги (SC W-1):**
- п. 8.2: 0.1%/день за непредоставление КС-2/КС-3
- п. 8.4: 50 000 руб за субподряд без согласования
- п. 8.6: 300 000 руб за алкоголь/наркотики на объекте
- п. 8.7: 10 000 руб/чел за работников без уведомления
- п. 8.8: 0.1%/день за просрочку возврата аванса
- п. 8.9: Убытки СВЕРХ неустойки
- п. 9.1.2: Право на односторонний отказ
- п. 9.1.3: Отказ при несоответствии материалов смете
- п. 9.4.2: Не оплачивать невыполненные работы при отказе
- п. 7.5: Соразмерное уменьшение цены

## Multi-Contract Systemic Fraud

Когда один подрядчик на нескольких договорах — искать **системные совпадения**:

- Одинаковые цены на работу (ПВХ-плитка 1 100 руб/м2 в обеих сметах)
- Одинаковый объём мусора (60 м3 при разном объёме демонтажа)
- Одинаковые бренды (Grohe 6 475 руб, Dulux Bindo 7, Kiilto 2 Plus)
- EGGER — decor code, не дверь (встречается в нескольких сметах одного подрядчика)

Совпадения = не случайность, а системная практика.

## Room Doors / RD Urban — идентификация производителя

При анализе дверей с указанием "EGGER H1145 ST10":
1. EGGER — производитель ЛДСП (ламинационного покрытия), не дверей
2. Код H1145 ST10 = decor "Дуб Бардолино натуральный", структура "шероховатые глубокие поры"
3. На маркировке двери искать фактического производителя
4. Пример: roomdoors.site (Новочебоксарск), бренд RD Urban / Room Urban
5. Каркасные двери из Чувашии — средний ценовой сегмент (~12 000-18 000 руб/комплект)
6. Разница между «дверью EGGER» и реальной дверью от Room Doors ~15 000-20 000 руб/шт

❗ **Критическое уточнение:** если заказчик или куратор проекта подтвердил, что в смете подразумевались ЛЮБЫЕ двери с ламинацией EGGER, то аргумент «EGGER не производит двери → введение в заблуждение» утрачивает силу. Формулировка «дверь EGGER» признаётся легитимной как «дверь с покрытием EGGER». Перед включением этого аргумента в переговорную позицию — проверить, как трактует сам заказчик.

## Pitfalls

- **Не путать decor code с product**: EGGER H1145 ST10 — это код ламинационного покрытия ЛДСП («Дуб Бардолино натуральный», структура ST10). EGGER не производит двери. Дверь с таким декором — от неизвестного завода.
- **Не принимать «рынок Москвы» за «рынок Саратова»**: региональные цены на работы — 50-65% от московских. На материалы — +/-15%.
- **Не игнорировать коммерческий статус**: юрлицо с гарантией 12 мес, ЭДО, сертификатами — дороже частника с Avito на 15-30%.
- **Docx-формат**: ссылки должны быть кликабельными hyperlinks, а не просто текстом. Использовать add_hyperlink() через OxmlElement.
- **Цены в ссылках**: если сайт блокирует — указать это в ограничениях, не врать что цена подтверждена.
- **Разделять confirmed vs expert**: в итоговой сумме явно указывать, сколько подтверждено прямыми ссылками, а сколько — экспертная оценка.
- **Не цепляться за опровергнутые аргументы.** Если подрядчик предоставил документы (счёт/УПД), подтверждающие цену — аргумент «цена не обоснована» снимается. Не продолжать настаивать на рыночной оценке. Пересчитать позицию, скорректировать переговорную позицию.

## Экономический эффект: предотвращённый vs возмещённый ущерб

После выявления завышений — классифицировать результат по двум категориям:

### Предотвращённый ущерб
То, что удалось НЕ ЗАПЛАТИТЬ благодаря выявлению завышения до выплаты.

```
Стяжка не выполнена, деньги не выплачены      531 200  → предотвращён
Мусор 60м3 — в смете, но ещё не оплачен        236 000  → предотвращён
Окраска 400 vs 310м2 — завышение               51 480   → предотвращён
```

**Формула:** `Общая смета — Реалистичная цена = Предотвращённый ущерб`
**Статус:** деньги у заказчика, не ушли подрядчику.

### Возмещённый ущерб
То, что удалось ВЕРНУТЬ или УДЕРЖАТЬ.

```
Неустойка по п.8.1 SC W-1             508 000  → взыскано
Соразмерное уменьшение по ст.723      1 011 000 → результат переговоров
Удержание 10% (п.2.6.2)               756 000   → временно удержано
```

**Формула:** `Фактически возвращено/удержано = Возмещённый ущерб`
**Статус:** деньги либо уже вернулись, либо не ушли.

### Итоговый экономический эффект
```
Эффект = Предотвращённый + Возмещённый
```
Итоговая цифра идёт в отчёт как результат работы СЭБ.

### Сценарии (3 точки отчёта)

| Сценарий | Предотвращённый | Возмещённый | Итого | Примечание |
|----------|----------------|------------|-------|-----------|
| C — Частичный | ~1 200 000 | ~500 000 | ~1 700 000 | Подрядчик уступил ~50% |
| A — Переговорный | ~1 800 000 | ~750 000 | ~2 550 000 | Рекомендуемый сценарий |
| B — Жёсткий | ~2 000 000 | ~1 500 000 | ~3 500 000 | Суд + неустойка + убытки |

**Важно:** Возмещённый ущерб ≠ прощённая неустойка. Если прощаете неустойку 508 000 в обмен на пересчёт цены — это не возмещённый ущерб, а инструмент переговоров. В отчёте писать: «Эффект 2 551 000 руб, из которых 507 800 — прощённая неустойка».

## Особый сценарий: документы от посредника («добросовестное приобретение»)

Когда подрядчик предоставляет счёт/УПД от посредника вместо документов от производителя:

### Что изменилось в позиции
- Паспорт от ликвидированного производителя может оставаться подделкой (ст. 327 УК РФ)
- Но подрядчик мог добросовестно не знать — он купил у посредника
- Товар физически установлен и реален

### Стратегический граф

```
Получены доки от посредника
├─ Цена в счёте ≈ рыночной (12-18 тыс) → завышение по материалу ОТПАДАЕТ
│  → Что остаётся: паспорт фальшивый + завышение по работе
│  → Стратегия: компромисс — снизить работу до рынка, 
│     паспорт признать ошибкой посредника, требовать нормальные доки
└─ Цена в счёте ≈ сметной (25-33 тыс) → цена для подрядчика ПОДТВЕРЖДЕНА
   → Аргумент «цена не обоснована» снимается — подрядчик реально заплатил
   → Что остаётся: паспорт фальшивый + завышение по работе
   → Стратегия: не настаивать на старом аргументе, а пересчитать позицию
     (завышение по материалу — 0, завышение по работе — пересмотреть)
   → Проверить аффилированность подрядчик↔посредник (совпадающие учредители/адреса)
```

**Правило:** если подрядчик предоставил счёт/УПД, подтверждающий цену, аргумент «цена не обоснована» снимается. Не продолжать настаивать на старом аргументе. Пересчитать позицию с учётом новых документов.

### Ключевые вопросы к документам посредника
1. Кто продавец? (название, ИНН) — проверить ЕГРЮЛ
2. Аффилирован ли посредник с подрядчиком? (совпадающие учредители, адреса)
3. Какая реальная цена закупки?
4. Есть ли сертификаты от производителя (не от посредника)?
5. Покрывает ли гарантия посредника 12 мес по договору?

### Что делать с паспортом от ликвидированной компании
- Паспорт недействителен независимо от добросовестности подрядчика
- Если подрядчик заблуждался — его проблема с посредником
- Заказчик вправе требовать паспорт от реального производителя
- Если не может предоставить — п. 9.1.3 SC W-1
- На переговорах: ослабить акцент на УК РФ (подрядчик «не знал»), усилить акцент на экономику (цена не обоснована)

- Арифметика сметы перепроверена
- Каждая позиция имеет либо подтверждённую ссылку, либо явную пометку «экспертная оценка»
- Учтён коммерческий статус объекта (если применимо)
- Ссылки кликабельны и ведут на реальные страницы
- Вывод содержит две цифры: по подтверждённым данным и общую оценку
