# Каскадное исключение работ (пирог конструкции)

## Когда использовать

При анализе строительных смет, когда подрядчик сообщает, что работа не выполнена. Не спрашивать про каждый слой отдельно — выявить базовую работу и исключить всё, что от неё зависит.

## Принцип

Если базовая конструктивная работа не выполнена — ВСЕ зависимые от неё последующие слои также не выполнены. Один вопрос тянет за собой 5-7 строк сметы.

## Типовые пироги

### Пирог пола
```
Стяжка не выполнена
  → Грунтовка под стяжку (бессмысленна)
  → Грунтовка под наливной пол (наливной без стяжки не делают)
  → Наливной пол (требует ровного основания)
  → ПВХ-плитка / финишное покрытие (кладётся на наливной)
  → Плинтус (монтируется к готовому полу)
  → Порожек (монтируется к готовому полу)
```

### Пирог стен
```
Шпаклёвка не выполнена
  → Грунтовка под окраску (без шпаклёвки не имеет смысла)
  → Окраска / обои (наносится на подготовленную поверхность)
```

### Пирог потолка
```
Каркас не смонтирован
  → ГКЛ / плиты Armstrong
  → Шпаклёвка / финиш
  → Окраска
```

### Пирог сантехники
```
Подводка не сделана
  → Монтаж прибора (унитаз, раковина)
  → Подключение и пусконаладка
```

## Как применять в переговорах

1. Один вопрос вместо пяти: «Стяжка выполнена?»
2. Если нет — исключить весь пирог одной фразой
3. Суммировать эффект: стяжка 531 000 + грунтовки 96 000 + наливной 261 000 + ПВХ-плитка 1 081 000 + плинтус 38 000 + порожек 800 = до 2 млн руб

## Источники данных

Для подтверждения невыполнения работ:
- Акт осмотра (фото)
- Журнал работ (даты)
- Показания инженера/куратора
- Собственный выезд на объект
