# Проверка строительных смет — методология ЭБ

## Когда использовать

Поступила смета от подрядчика. Задача — найти завышения, признаки фрода, оценить экономический эффект и подготовить позицию для переговоров.

## Предварительный сбор контекста (ОБЯЗАТЕЛЬНО)

До начала анализа запросить у пользователя:
- Регион работ (Москва/регионы — цены ×1.5-3)
- Дата сметы (ставка НДС)
- Тип объекта (офис/производство/ЦОД/жильё — разные нормативы и профиль завышений)
- **Номера договоров** — проверить п. 4.3 каждого на наличие SC W-1
- Статус подрядчика (тендер/рекомендован/свой)
- Есть ли альтернативные КП

## ПРЕДВАРИТЕЛЬНОЕ ЧТЕНИЕ ВСЕХ ФАЙЛОВ ПРОЕКТА (mandatory)

Перед началом анализа — открыть папку проекта и прочитать ВСЕ .docx файлы (read_file с автопреобразованием). Пользователь может не вспомнить/не назвать все документы.

Особое внимание:
- **GC + SC** — общие и специальные условия договора (содержат ключевые рычаги: ст. 336, 443, 460 GC, п. 8.1, 9.1.3 SC W-1)
- **Письма/служебки** — позиция сторон, выявленные нарушения
- **Более ранние версии анализов** — могут содержать информацию, не вошедшую в финал (например, расчёт неустойки, контакты участников)
- **Корректировка видения** — если есть документ, где сравниваются ответы разных людей — это ключевой источник расхождений
- **Запросы на документы** — какие документы уже запрашивались, в какие сроки

Правило: если в папке 20+ файлов, а прочитано 3 — значит 17 потенциально содержат данные, которых нет в прочитанных. Читать все.

## Слой 1 — Арифметическая верификация

```
объём × цена_работ = строка_работ
объём × цена_материалов = строка_материалов
сумма_работ + сумма_материалов = база
база × 1.22 = итог_с_НДС (НДС 22% с 01.01.2026)
```

Проверить каждую строку, итоги по столбцам, итог по смете.
Расхождение > 0.5% — грубая ошибка или намеренное завышение.

## Слой 2 — Верификация физических объёмов

### Кросс-анализ нескольких смет одного подрядчика (ОБЯЗАТЕЛЬНО при >1 договоре)

Когда у пользователя два и более договора с одним подрядчиком на смежные объекты — выполнить кросс-анализ:

1. Запросить ВСЕ договоры (пользователь может не сказать о втором).
2. Составить матрицу совпадений: Позиция | Договор А | Договор Б | Вывод
   - Одинаковые объёмы (60 м3 мусора) = ШАБЛОН
   - Одинаковые цены работ (ПВХ-плитка 1 100/м2) = ЦЕНОВОЙ ШАБЛОН
   - Одинаковые цены материалов до рубля (Grohe 6 475) = ШАБЛОН КОПИПАСТЫ
   - Разные цены на одинаковые позиции = НЕСОГЛАСОВАННОСТЬ
3. 3+ совпадения = системная практика, не случайность
4. В переговорах предъявлять как системный риск, а не отдельные ошибки

### Расчёт объёма мусора по ГЭСН-2001 (приложение 1)

Коэффициенты разрыхления:
| Материал | Коэфф. |
|----------|--------|
| Бетон, стяжка цементная | 1.5-1.6 |
| Кирпич | 1.4-1.5 |
| Керамическая плитка | 1.5-1.6 |
| ГКЛ, потолки Armstrong | 1.2-1.3 |
| Древесина | 1.3-1.4 |
| Линолеум | 1.1-1.2 |

Формула: `S (м²) × толщина (м) = плотный_остаток (м³) × коэфф = объём_с_разрыхлением (м³)`

**Критический индикатор:** 60 м³ в нескольких сметах одного подрядчика = системный шаблон

### Обратный расчёт материалов
- Стяжка 50 мм на 415 м² = 20.75 м³ × ~5 000 ₽/м³ = ~104 000 ₽ (проверить, не завышена ли цена в смете)
- Расход краски: ~0.1-0.15 л/м² на слой, 2 слоя

## Слой 4 — Проверка цены материалов

### Рабочие источники (из-за рубежа)

**Stroylandiya** — слайдер цен в HTML, работает через curl. Использовать основной домен (stroylandiya.ru) — саратовский поддомен (saratov.stroylandiya.ru) возвращает 503 с июля 2026:
```bash
curl -s -L "https://stroylandiya.ru/search/?q=наливной+пол+Bergauf" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
```
Извлечение: `re.findall(r'data-min="(\d+)" data-max="(\d+)"', html)`
- data-min == data-max = точная цена единственного товара
- data-min < data-max = диапазон цен по всем найденным

- EGGER Russia — egger-russia.ru — каталог декоров, без розничных цен.
- tdserver.ru — дистрибьютор ЛДСП EGGER.
- Avito (регион работ) — 1 запрос работает, затем rate-limit IP.

### Проверка специализированного оборудования
Для прецизионных кондиционеров, газового пожаротушения, Q-SPACE коридоров и прочего ЦОД-спецоборудования:
- Цены на монтаж/обслуживание сильно зависят от региона и наличия сертифицированных подрядчиков
- Единичные расценки из открытых источников (Stroylandiya, Avito) не применимы — требуется КП от профильных подрядчиков
- Ориентир: перенос прецизионного кондиционера 25кВт — требует КП, предв. 120-200 тыс/шт (не 300+)
- Ориентир: хладон 125 — цена зависит от года и волатильна, запросить КП; после 2022 возможен рост до 1 000-1 500 руб/кг
- Ориентир: модули газового пожаротушения МПГ — 150-280 тыс/шт в зависимости от комплектации, требует КП
- Соотношение монтаж/оборудование для Q-SPACE: монтаж не должен превышать 20-25% от стоимости оборудования

### Извлечение цен с Авито (услуги)

Авито (https://avito.ru) — работает через curl, но с rate-limit (429 после 1-2 запросов с одного IP):

```bash
# Первый запрос — работает. Извлечение цен из JSON-поля "priceDetailed"
curl -s -L "https://www.avito.ru/saratov/predlozheniya_uslug?q=укладка+плитки" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36" \
  | grep -oP '"priceDetailed":\{[^}]*"value":\d+' | grep -oP 'value":\d+' | grep -oP '\d+'
```

Ограничения: после первого успешного запроса IP блокируется на ~30-60 мин (429). Стратегия: выполнить все нужные запросы в одном curl batch, сохранить HTML, потом разобрать локально.

### Пересчёт расхода материалов (мешок/пачка → руб/м2)

При сравнении цен материалов из розницы (цена за мешок/пачку/литр) с ценой в смете (руб/м2) — ОБЯЗАТЕЛЬНО пересчитать через нормативный расход:

```python
# Bergauf Easy Boden 20кг: 626 руб/мешок
# Расход: 1.5 кг/мм/м2
# Слой 10мм → 15 кг/м2 → 0.75 мешка/м2
# Цена материала: 0.75 × 626 = 470 руб/м2
# Смета: 350 руб/м2 → ниже рынка (выгодно заказчику)

# Dulux Bindo 7 9л: 5 000 руб/ведро
# Расход: 80-100 мл/м2/слой, 2 слоя → 160-200 мл/м2
# 9л / 0.18 л/м2 = 50 м2/ведро
# 400 м2 / 50 = 8 вёдер × 5 000 = 40 000 руб (смета 79 008)
```

Типовые нормы расхода:
| Материал | Расход |
|---------|--------|
| Наливной пол (10мм) | 15 кг/м2 = 0.75 мешка/м2 |
| Штукатурка гипсовая (10мм) | 8.5 кг/м2 |
| Краска (2 слоя) | 0.16-0.20 л/м2 |
| Плиточный клей | 3-5 кг/м2 |

### Ключевое: EGGER H1145 ST10 — не модель двери

EGGER H1145 ST10 — это код декора ламинации ЛДСП:
- H1145 = «Дуб Бардолино натуральный» (decor)
- ST10 = «Шероховатые глубокие поры» (surface structure)
- EGGER производит ЛДСП (мебельные плиты), а НЕ двери
- Дверь в смете — безымянная (nameless) от неизвестной фабрики с ламинацией EGGER
- Применение: п. 9.1.3 SC W-1 (несоответствие материалов), если в смете указано как «дверь EGGER»

1. Фото паспорта: производитель, дата, ОТК
2. Пробить производителя в nalog.gov.ru (ЕГРЮЛ)
3. Если ликвидирован до даты паспорта — возможна ст. 327 УК РФ

## Слой 5 — Логическая связность работ

- Демонтаж «с сохранением» → обратный монтаж: объёмы совпадают? Цена демонтажа должна быть на 30-50% ниже обычного (аккуратная разборка, а не снос).
- Двойные работы: одна операция дважды с разной ценой
- **Несоответствие объёмов смежных этапов:** объём окраски/покрытия не может значительно превышать объём подготовки (шпаклёвка, грунтовка). Проверять: Σ(окраска+обои) ≤ Σ(шпаклёвка+грунтовка) × 1.1 (на откосы/колонны). Расхождение >10% — завышение или дубль.
- Разные сечения демонтажа и монтажа: физически несовместимо
- Грунтовка ×2 (под стяжку и под наливной пол) — ЛЕГИТИМНО, разные этапы
- **Формулировка «Демонтаж/Монтаж» как одна работа** — классический приём: работа названа «демонтаж/монтаж», но цена соответствует сумме двух работ. Требовать разделение: демонтаж отдельно, монтаж отдельно, с разными ценами.

## Слой 6 — Проверка НДС и накладных

- НДС 22% (с 01.01.2026, ст. 164 НК РФ)
- В смете «с НДС» работа и материалы в таблице — без НДС
- Накладные расходы: обычно 10-20% от ФОТ
- Сметная прибыль: обычно 8-12%

## Слой 7 — OSINT компании (ЕГРЮЛ)

### Проверка производителя/поставщика
- nalog.gov.ru — статус, дата ликвидации, причина
- kad.arbitr.ru — судебные дела
- fssp.gov.ru — исполнительные производства
- fsa.gov.ru — сертификаты соответствия

### Red flags
- Статус: ликвидировано / исключено за недостоверные сведения
- Уставный капитал ≤ 10 000 руб
- Сотрудников ≤ 5
- Доходы не соответствуют контракту

### Если компания ликвидирована до даты паспорта — КРАСНЫЙ ФЛАГ

Факт: паспорт изделия датирован после ликвидации юрлица — это аномалия.

**Правило доказательности:** не переходить сразу к уголовной квалификации. Формулировки только условные:
- «Требует проверки: дата паспорта (X) ПОСЛЕ ликвидации (Y). Необходимо установить…»
- «Если подтвердится сознательное использование — возможна квалификация по ст. 327 УК РФ»

Что нужно для подтверждения:
1. Фото/скан паспорта изделия (есть)
2. Выписка ЕГРЮЛ о ликвидации (есть)
3. Факт установки на объекте (проверить при осмотре)
4. Доказательство, что подрядчик ЗНАЛ о ликвидации (нет — требует запроса)
5. Экспертное заключение о подлинности печати/подписи (нет — требует назначения)

До получения п.3-5 — указывать как «красный флаг, требует проверки», не как «подделка».

## Слой 8 — Общие нормы ГК РФ

Если в договоре нет специальной неустойки за просрочку:
| Статья | Что даёт | Формула |
|--------|----------|---------|
| Ст. 395 | Проценты за чужие деньги | аванс × ключевая ставка / 365 × дни |
| Ст. 723 | Соразмерное уменьшение цены | разница сметной и рыночной цены |
| Ст. 715 | Отказ + убытки | расторжение + разница с новым подрядчиком |
| Ст. 1102 | Неосновательное обогащение | выплачено сверх фактического |
| Ст. 431.2 | Недостоверные заверения | штраф 10% — если предусмотрен договором (п. 4 ст. 431.2 / ст. 406.1 ГК) |

## Слой 9 — Специальные условия SC W-1 (ВымпелКом)

**Применимость:** если в договоре п. 4.3.x есть ссылка на SC W-1.
**Цепочка цитирования:** «п. 4.3.X договора №ХХХ (SC W-1 → п. 8.1)»

### П. 8.1 — Неустойка за просрочку работ
| Период | Ставка | Пункт |
|--------|--------|-------|
| < 14 дней | 0.2%/день | 8.1.1 |
| 14-30 дней | 0.3%/день | 8.1.2 |
| > 30 дней | 0.4%/день | 8.1.3 |

Ставка применяется на ВЕСЬ период с первого дня (не прогрессивно).
Формула: **Работы (не материалы) × ставка × дни просрочки**

### Дополнительные рычаги
| Пункт | Что даёт |
|-------|----------|
| 7.5 | Соразмерное уменьшение (при дефектах, не при завышении цен) |
| 7.4 | Односторонний акт о недостатках |
| 8.2 | 0.1%/день за просрочку закрывающих документов (только после завершения работ) |
| 8.3 | 0.1%/день за просрочку устранения недостатков |
| 8.4 | 50 000 руб за субподрядчиков без согласования |
| 8.6 | 300 000 руб за алкоголь/наркотики (с фото/видео) |
| 8.7 | 10 000 руб за каждого работника без уведомления |
| 8.8 | 0.1%/день за просрочку возврата аванса |
| 8.9 | Убытки сверх неустойки (неустойка штрафная) |
| 9.1.2 | Односторонний отказ при просрочке |
| 9.1.3 | Отказ при несоответствии материалов |
| 9.4.2 | При отказе по вине подрядчика — не оплачивать невыполненные работы + возврат аванса за 10 дней |

### Важные уточнения
- **П. 8.2** — не применять, пока работы не завершены
- **П. 7.5** — применяется к ДЕФЕКТАМ качества, не к завышению цен. Завышение цен → п. 2.4 договора или ст. 1102 ГК РФ
- **П. 2.6.2 (10% удержание)** — не рычаг, пока не начались выплаты
- **10% holdback** — только если платежи уже шли. Если не платили — leverage в том, что деньги ещё у заказчика

## Слой 10 — Экономическая модель (3 сценария)

| Сценарий | Эффект от сметы | Условия |
|----------|----------------|---------|
| A — МИНИМАЛЬНЫЙ | ~10-15% | Подрядчик уступает ~50% очевидных завышений |
| Б — РЕАЛИСТИЧНЫЙ | ~25-35% | Полный пересчёт по рынку + удержание 10% |
| В — МАКСИМАЛЬНЫЙ | ~35-45% | Пересчёт + удержание + неустойка SC 8.1 + ст. 395 |

Пример расчёта (два договора, просрочка 40+25 дней):
```
Договор 1: работы 1 991 338 × 0.4% × 40 = 318 614 ₽
Договор 2: работы 2 522 480 × 0.3% × 25 = 189 186 ₽
Итого неустойка: 507 800 ₽ (~7 965 + 7 567 ₽/день)
```

## Слой 11 — Стратегия переговоров

### Этап 1 — Подготовка (1-2 дня)
1. Собрать платёжные документы (сколько выплачено)
2. Техосмотр с замером фактических объёмов (лично или через инженера)
3. Запросить у подрядчика: накладные, сертификаты, акты утилизации, журнал работ
4. Запросить ВСЕ договоры и приложения (SC + GC)
5. OSINT производителей материалов

### Вопросы инженеру (email — финансовые/документальные):
- Какие КС-2/КС-3 подписаны, сколько выплачено?
- Сертификаты на материалы получены?
- Журнал работ ведётся? Дата начала работ?
- Уведомления о просрочке были?

### Вопросы на объекте (физические замеры):
- Фактическая площадь стяжки/плитки/окраски
- Фото маркировки дверей (торец), смесителей, раковин
- Визуальный контроль качества (трещины, покрытие)

### Критическое правило: пересчёт после КАЖДОГО ответа
- «Стяжку не заливали» → немедленно вычесть строку (~531 000 ₽)
- «Акты не подписаны» → 100% leverage
- «Деньги не перечислены» → полный финансовый рычаг
- После каждого ответа — пересчитать 3 сценария и переранжировать варианты

### Этап 2 — Переговоры (3-7 дней)
1. Личная встреча на объекте
2. Предъявить: завышение, просрочку, несоответствие материалов
3. Кнут: неустойка SC 8.1 + отказ от подписания актов
4. Пряник: отказ от взыскания в обмен на пересчёт сметы
5. Зафиксировать допсоглашением: новая цена + новый график

### Этап 3 — Жёсткая фаза
1. Уведомление об отказе от договора (п. 9.1.2 SC или ст. 715 ГК)
2. Не оплачивать невыполненные работы (п. 9.4.2)
3. Поиск нового подрядчика (фиксация убытков)
4. Независимая экспертиза
5. Досудебная претензия → арбитраж

**Ключевой рычаг:** акты КС-2 не подписаны → деньги не выплачены. Пока акты не подписаны — деньги у заказчика.

### Генерация файлов

После завершения анализа создать (через python-docx, python-pptx), в порядке приоритета:

**0. `Executive_Summary_[объект].docx`** — 2-3 страницы для руководителя. **Это ГЛАВНЫЙ документ при multi-contract проектах.** Детальные анализы — справочно.

**Ключевое правило Executive Summary:** раздел 1 (Ключевые цифры) должен содержать **детальные таблицы по каждому пункту**, а не просто строки с цифрами. Каждый пункт — отдельный подраздел 1.1-1.9 с таблицей и кратким пояснением. Сводные цифры без таблиц (бюджет, завышение, неустойка) недостаточны для принятия решений — нужна раскладка по договорам с источниками.

**Запрещено:** указывать имена файлов в пояснениях (вроде «Источник: файл.docx»). Факты подтверждаются ссылками на пункты договоров/кодексов или общими формулировками: «Сравнение с Авито, Стройландия». Ссылки на конкретные файлы — в футере или примечании в конце.

Структура Executive Summary (8 блоков):
1. **КЛЮЧЕВЫЕ ЦИФРЫ** (крупно, по центру, цветом): бюджет, завышение (красный), целевая цена (зелёный), экономия
2. **СУТЬ ПРОБЛЕМЫ**: 3-5 фактов, не требующих экспертизы (подтверждённые: стяжка не сделана, просрочка, мусор-шаблон; красные флаги: EGGER-двери)
3. **СВОДНАЯ ТАБЛИЦА договоров**: работы/материалы/завышение/к оплате (красное/зелёное)
4. **УЧАСТНИКИ**: таблица с ролями, контактами, риском лояльности. Если Баранов под подозрением — предупреждение красным
5. **ПРИЗНАКИ СИСТЕМНОСТИ** (кросс-смета): таблица совпадений для >1 договора
6. **ЭКОНОМИЧЕСКАЯ МОДЕЛЬ**: таблица сценариев с колонкой «Входит в эффект» (снижение цены / прощение неустойки / убытки), чтобы сумма эффекта НЕ противоречила сумме бюджета. Если эффект включает прощение неустойки — указать явно: «из 2 552 000 эффекта — 507 800 составляет прощённая неустойка, не входящая в цену».
7. **ПЛАН ДЕЙСТВИЙ**: таблица № | Действие | Срок | Ответственный
8. **РЕШЕНИЕ: поля для подписи руководителя**

**Корректировка_видения при конфликте источников** — если два человека (старший/инженер) дают РАЗНЫЕ ответы на одни вопросы, сформировать отдельную таблицу расхождений:
| Вопрос | Ответ А | Ответ Б | Анализ | Действие |
Каждое расхождение разобрать: могли ли оба говорить правду (разный уровень информированности)? Если да — не выбирать, а фиксировать обе версии и рекомендовать проверку.

**Сценарии переговоров с вероятностями** — в стратегии указывать не только сценарии, но и примерную вероятность:
- Мирный: ~60% (согласен на пересчёт + новый график)
- Торг: ~25% (торгуется, но в целом согласен)
- Отказ: ~10% (отказывается, работы стоят)
- Исчезновение: ~5% (бросает объект)

**Стратегическая рамка** — в рекомендациях формулировать: «Цель — завершить проект качественно и в срок, а не наказать подрядчика. Судебные тяжбы — 3-6 мес. Лимит времени заказчика — часто 1 мес. Мирное завершение выгоднее.»

1. `Анализ_сметы_[объект].docx` — подробный анализ
2. `Презентация_[объект].pptx` — 8-12 слайдов для встречи
3. `Стратегия_[объект].docx` — пошаговый план
4. `Экономический_эффект_[объект].docx` — 3 сценария

### Стандарты качества документа — обязательная проверка

Перед выдачей пользователю каждый .docx обязан содержать:

**Критерии рисков явно указаны** перед таблицей сравнения:
- "КР = завышение >100% ИЛИ сумма >50 000 руб"
- "ВЫС = 50-100% ИЛИ 10 000-50 000 руб"
- "СР = 20-50%. НИЗКИЙ = до 20%"

**Источники содержат конкретные URL поисковых запросов**, а не только домены:
- stroylandiya.ru/search/?q=Bergauf+Easy+Boden+20 (не просто stroylandiya.ru)
- market.yandex.ru/search?text=Royal+Thermo (не просто market.yandex.ru)

**Противоречия в цифрах устранены** — если в документе есть 27% и 22%, должно быть пояснение: «27% без коммерческой надбавки, 22% с надбавкой».

**Рекомендации содержат сроки и ответственных:**
- "Ответственный: руководитель проекта. Срок: 3 рабочих дня."

**Приложения с готовыми шаблонами:**
- **Приложение 1**: Шаблон служебной записки (гриф ДСП, императив)
- **Приложение 2**: Шаблон email-запроса подрядчику

### Верификация встречных документов (счета, УПД, накладные)

Когда подрядчик или внутренний куратор предоставляет счёт/УПД/накладную в ответ на запрос — не принимать на веру, а проверять:

**1. Кто продавец?** (название, ИНН) — проверить по ЕГРЮЛ: действует или ликвидирован. Если ИП — проверить статус.

**2. Кто производитель?** Указан ли в счёте/накладной производитель товара (не путать с продавцом). Если производитель не указан — запросить дополнительно.

**3. Цена в счёте vs смета:**
- Если цена в счёте ≈ сметной → завышение по материалу отсутствует (завышение может быть только по работе)
- Если цена в счёте < сметной → завышение по материалу, добавить в расчёт
- Если цена в счёте > сметной → подрядчик работает в убыток по материалу (маловероятно, проверить аффилированность продавца)

**4. Дата счёта/УПД vs дата паспорта/сертификата:**
- Если счёт после ликвидации производителя → цепочка гарантии обрывается
- Если счёт до ликвидации → возможна перепродажа старых запасов, гарантия от посредника

**5. Перечень товаров:**
- Соответствует ли спецификации в смете?
- Есть ли фурнитура отдельно (петли, ручки, замки) или включена в цену двери?
- Если фурнитура отдельно — сравнивать полную стоимость комплекта, а не только «двери»

**Правило:** счёт/УПД не закрывает вопрос, а открывает новые. После получения — пересчитать позицию (завышение по материалу может уменьшиться или исчезнуть, завышение по работе остаётся).

## Pitfalls

- **Московские цены для регионов** — дают ложное завышение. Применять региональный коэффициент.
- **Калибровка рисков:** не допускать >30% позиций с грифом КР. Использовать ДВА критерия: % завышения И сумму переплаты. Позиция на 2 000 руб с завышением ×2 — это НИЗКИЙ, не КР.
- **Сравнение цен «мешок vs м2»:** цена Bergauf 626 руб/мешок ≠ 626 руб/м2. ОБЯЗАТЕЛЬНО пересчитывать через расход/м2 (см. Слой 4, раздел «Пересчёт расхода материалов»). Без пересчёта — грубая ошибка в анализе.
- **НДС 20%** — устаревшая ставка. С 2026 — 22%.
- **Leroy Merlin** — не существует в РФ с 2024. Только Лемана ПРО (lemanapro.ru).
- **Двойная грунтовка** (под стяжку + под наливной пол) — легитимна, разные этапы.
- **Несоответствие объёмов смежных этапов** — объём окраски не может превышать объём шпаклёвки/грунтовки без обоснования (откосы, колонны). Проверять как отдельный шаг.
- **EGGER — не производитель дверей.** Производитель ЛДСП. Проверять по паспорту.
- **Коммерческая наценка** — юрлица платят на 15-30% больше розницы.
- **Инфляция** — если смета старше 2-3 мес, допуск 2-5%.
- **Не сдаваться при блокировке** — пробовать curl с YaBrowser UA, разные эндпоинты, запросить ссылки у пользователя.
- **Пересчёт после каждого ответа инженера** — каждое новое данное меняет цифры и стратегию.
- **Файлы .docx блокируются Windows (Word открыт).** Сохранять во /tmp, потом копировать (shutil.copy2). Если PermissionError — сохранить как _NEW.docx.
- **document-critic: все замечания за 1 батч.** Пользователь явно отвергает подход «оставим на следующую итерацию». После document-critic все найденные замечания исправлять в ОДНОМ батче, потом повторная проверка.
- **Преждевременная уголовная квалификация (ст.327/159 УК РФ).** Не включать уголовные статьи в Executive Summary или сводку, пока нет:
  1. Фото/скана паспорта изделия (есть)
  2. Выписки ЕГРЮЛ о ликвидации (есть)
  3. Подтверждения установки на объекте (осмотр)
  4. Доказательства, что подрядчик ЗНАЛ о ликвидации (запрос)
  5. Экспертного заключения (назначается)
  До п.3-5 — формулировка: «требует проверки, красный флаг. Если подтвердится — возможна квалификация по ст.327 УК РФ». Не «подделка», не «мошенничество».
- **Полные номера договоров, не «Дог.1»/«Дог.2».** В документах для руководителя использовать ПОЛНЫЕ номера (26114837, 26127673), а не краткие «Дог.1»/«Дог.2». Пользователь явно указал: «у договоров есть номера — оперируем ими». Сокращения допустимы только в цепочке цитирования (п. 4.3.7 договора №26114837 → SC W-1 → п. 8.1), где номер уже указан.

### ЦОД-специфика (дополнительные pitfalls)
- **Избыточный ЗИП газового пожаротушения** — часто раздувают тройным дублированием. Норма запаса определяется проектом, ориентир 10-15% от объёма. Проверять проектное обоснование.
- **Прецизионные кондиционеры** — цена пероса внешнего блока 25кВт >300 тыс/шт — завышение. Требовать КП от профильного подрядчика.
- **Q-SPACE горячие коридоры** — стоимость монтажа не должна превышать 20-25% от стоимости оборудования. Проверять пропорцию.

## Обновление скилла по результатам проверки

После завершения анализа каждой новой сметы скилл должен пополняться:

### Что сохранять
1. **Новые рыночные цены** — подтверждённые через КП или открытые источники (позиция, цена, регион, дата, источник)
2. **Новые схемы завышений** — ранее не встречавшиеся (например, «демонтаж/монтаж» как одна работа)
3. **Новые источники данных** — сайты/сервисы, которые работают для данного региона
4. **Уточнённые региональные коэффициенты** — фактические отклонения от заложенных в скилле
5. **Новые юридические аргументы** — статьи/пункты, которые сработали в переговорах
6. **Исправления ошибок** — если в процессе анализа обнаружилось, что какое-то утверждение скилла неверно

### Куда сохранять
- `references/accumulated-knowledge.md` — основной накопитель: цены, схемы, источники, уточнения
- Сам SKILL.md — если обнаружена ошибка в методологии (patch через skill_manage)

### Формат записи в accumulated-knowledge.md

```markdown
## [Дата] — [Объект/договор], [Регион]

### Подтверждённые цены
| Позиция | Цена (руб) | Регион | Источник |
|---------|-----------|--------|----------|

### Новые схемы завышений
- [описание схемы] — [как выявлено]

### Новые источники
- [URL] — [что даёт]

### Уточнения коэффициентов
- [регион]: заложено [X], по факту [Y]

### Исправления
- [что было неверно] → [как исправили]
```

### Когда сохранять
Сразу после завершения анализа, перед выдачей результата пользователю. Если в процессе анализа обнаружена ошибка в самом скилле — исправить немедленно через skill_manage(action='patch').
