# Шпаргалка — ТЦП 2621 (проверка смет на БС)

## Порядок проверки сметы по ТЦП
1. Найти каждую позицию сметы в прайсе (references/tcp-2621-prices.md) по номеру п. или названию.
2. Сверить цену (руб, без НДС) и единицу измерения.
3. Проверить примечание позиции: применимость, коэффициенты, несовместимости.
4. Проверить общие примечания 1–11 (транспорт, материалы, альпинизм, хранение).
5. Проверить, что не применены повышающие коэффициенты без документального основания (Прим. 8).
6. При «по согласованию» — коэффициенты не применяются (Прим. 11).

## Быстрые признаки завышения
- **Транспорт/командировки заявлены отдельно** → уже включены (кроме заполярья/вахты по согласованию).
- **Монтажная лента, изолента, герметик, наконечники, хомуты, стяжки отдельной строкой** → включены (Прим. 7).
- **Хранение оборудования на складе подрядчика < 6 мес.** → включено (Прим. 10).
- **Промышленный альпинизм отдельной строкой** → включён (Прим. 6).
- **Материалы для СМР по завышенным ценам** → компенсация только по документам профильного поставщика (Прим. 9).
- **Несовместимые пункты в одной смете** → двойная оплата (см. список ниже).
- **Несколько БС на позиции** → скидка 25% на каждую после 1-й (3.1.1/3.1.2/3.4.1).
- **Повышающие коэффициенты (ночь/выходные)** → только по согласованию и только к работам, не к материалам (2.70.1/2.70.2).

## Термины
- **ТЦП** — тарифно-ценовые показатели (прайс подрядчика на работы по БС).
- **ОТР** — общие технические решения (результат ППО, согласуется с Заказчиком).
- **РД** — рабочая документация; марки: СП, АС, ТХ, ЭС, ОВ, ПТ, КМ.
- **СИВ** — суммарная интенсивность взаимодействия (расчёт для СанЭпидЗаключения).
- **ПДШХ** — предельно допустимая шумовая характеристика.
- **ПНР** — пусконаладочные работы.
- **Easy Macro / Small Cell / RRU / RRH / RFM** — типы оборудования БС.
- **FSES / УЗИП** — блоки защиты от перенапряжения радиомодулей.
- **ЩУБС** — шкаф учёта и распределения БС (с АИИСКУЭ-модулем).
- **ГЗШ** — главная заземляющая шина.
