# Шаблон письма внутреннему стейкхолдеру — запрос решений

## Пример из кейса ЦПК Саратов (июль 2026)

```
Баранов С.А.

По итогам анализа смет по договорам 26114837 и 26127673 (ЦПК Саратов,
ООО «СТРОЙСПЕЦТЕХНОЛОГИЯ СК») прошу определить позицию по следующим вопросам:

1. НЕУСТОЙКА (п. 8.1 SC W-1)
   Начислено на 27.07.2026 — 697 249 руб
   (дог.26114837: 374 371 = 1 991 338 × 0,004 × 47 дн;
    дог.26127673: 322 877 = 2 522 480 × 0,004 × 32 дн).
   Ежедневное начисление — +18 055 руб/день.
   Ваше решение: взыскиваем, прощаем при переговорах, или частично?

2. ВЫВОЗ МУСОРА (оба договора)
   В обеих сметах заложено 60 м³. Реальный объём —
   38 м³ (дог.26114837, расчёт: стяжка 50 мм × 415 м² = 20,75 м³
   + прочий демонтаж ~17 м³) и ~15 м³ (дог.26127673, расчёт:
   Armstrong 120 м² = 3,1 м³ + плитка 140 м² = 2,7 м³ + двери
   18 шт = 6,7 м³ + упаковка = 2,5 м³).
   Общее завышение — 236 000 руб. Основание для соразмерного
   уменьшения цены — п. 7.5 SC W-1.
   Предъявляем подрядчику или считаем коммерческой скидкой
   при пересчёте?

3. ОКРАСКА СТЕН (дог.26127673)
   В смете 400 м² при базовой площади стен 310 м².
   Излишек 90 м² — 51 480 руб.
   Основание для соразмерного уменьшения цены — п. 7.5 SC W-1.
   Ваше решение по этому пункту?

4. ДВЕРИ — ЗАПРОС В КОМПЛАЕНС
   Подрядчик предоставил счёт и УПД от посредника,
   подтверждающие цену дверей. Однако изначально
   предоставленный паспорт изделия выдан ООО «РУМДОРС» —
   организацией, ликвидированной 16.01.2024, тогда как
   паспорт датирован 09.06.2026. Документ заведомо
   недействителен.
   Прошу инициировать запрос в комплаенс: насколько
   корректно с точки зрения деловой этики и комплаенс-
   политики ПАО «ВымпелКом» принимать и оплачивать
   работы, по которым предоставлен фиктивный паспорт
   изделия?

Срок по первому вопросу критичный — неустойка капает
каждый день. Остальные — в рамках подготовки к переговорам.

Жду ответ.
```

## Принципы

| Элемент | Как оформлять |
|---------|---------------|
| Номера договоров | Только полные (26114837), не «дог.1» |
| Обоснование цифр | Краткий расчёт в скобках, 1-2 строки |
| Правовое основание | С указанием цели: «для соразмерного уменьшения цены — п. 7.5 SC W-1» |
| Вопрос | Всегда запрос решения, не констатация |
| Комплаенс | Отдельным пунктом, если есть этический риск |
| Срочность | Указать только по действительно срочным пунктам |
