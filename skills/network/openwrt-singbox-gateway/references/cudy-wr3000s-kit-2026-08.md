## Факты прошивки (wiki openwrt.org/toh/cudy/wr3000s_v1)
- UART: 115200 8N1; вход в U-Boot shell — питание + держать Reset
- TFTP: ПК 192.168.1.88, файл переименовать в `cudy3000s.bin`
- Команды: `tftpboot 0x46000000 cudy3000s.bin; bootm 0x46000000`
- MTD (NAND 128MiB, NMBM): BL2 / u-boot-env / Factory / bdinfo / FIP / ubi
- Железо (из boot-логов): MT7981 1300 МГц, DDR3 256 МБ, ARM64 (aarch64),
  1x 2.5G (WAN, mt7530) + 4x 1G LAN
