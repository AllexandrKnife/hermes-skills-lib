# Конвейер написания ВАК-статьи (проверен 15.08.2026, 5 статей)

Полный цикл «тема → готовая статья в ВАК-формате» для публикационного
цикла исследователя. Каждая статья = папка `Статьи_2026/<тема>/`
с подпапками data/, code/, draft/, final/; финалы копируются в
`Готовые_статьи/`.

## Конвейер (7 шагов)

1. **ДАННЫЕ — реальные, с источниками.** Скачать/собрать: MOEX ISS API
   (капитализация, `curl` к iss.moex.com — работает без ключа),
   Росстат XLS (`curl -k` — у rosstat.gov.ru битый SSL, exit 60 без -k;
   парсинг xlrd), открытая отчётность, пресс-релизы. Каждое число —
   с URL-источником. Проектные допущения помечать «допущение (оценка)».
   Проверка: N строк, нет дублей, поля соответствуют описанию.
2. **РАСЧЁТ — кодом.** Скрипт по скилам ядра (eko-core): Монте-Карло,
   Tobin Q, DiD-дизайн, ML (sklearn — установлен). Seed фиксирован,
   результаты в data/*.txt. Sanity: p5<mean<p95, суммы сходятся,
   детерминированная модель согласована со средним симуляции.
3. **ТЕКСТ — по разделам, частями.** draft/01_titul_vvedenie.txt,
   02_obzor_metod.txt, 03_rezultaty..., 04_zakl_literatura.txt.
   ВАК-структура: титул, аннотация (200-250 слов), ключевые слова,
   JEL, введение, обзор, данные и метод, результаты, обсуждение,
   заключение, список литературы (ГОСТ, сквозная нумерация [1]-[N]).
   Ссылки в тексте — номерами [N]; при перенумерации списка —
   синхронизировать ВСЕ вхождения (баг: номера разъехались при
   добавлении позиций — фикс патчами по строкам).
4. **ВЕРИФИКАЦИЯ — скриптом, а не глазами.** (а) Ссылки: каждая [N] в
   тексте определена в списке и наоборот; парсер составных ссылок —
   `\[(\d+(?:\s*,\s*\d+)*)\]` (простой `\[(\d+)\]` не ловит `[5, 6]`).
   (б) Цифры: сверка статьи с data-файлом через norm() =
   `re.sub(r"\s","",s.replace(",","."))` — русская запятая vs точка.
   (в) Арифметика: проценты, суммы, платежи пересчитывать с нуля
   (аннуитет: pmt = P*r/(1-(1+r)^-n)).
5. **КРИТИКА.** document-critic слои 1-3 обязательны (арифметика,
   источники, противоречия), слой 9 — reviewer.py --triz (exit 0 = OK;
   обёртка subprocess с input=text, pipe `cat | python3` блокируется
   security-сканом). Для статей-дизайнов (событие ещё не наступило) —
   честно: «дизайн + базовая линия, количественная оценка после данных»,
   не выдавать прогноз за факт.
6. **ВЁРСТКА.** Выключка по ширине 80 (txt-document-layout: склейка
   абзацев → justify_paragraph) + выравнивание таблиц
   (scripts/align_tables.py). Широкие таблицы (>80) ужать значениями.
   Проверка: 0 строк >80.
7. **ГОТОВЫЕ.** Копия final/статьи в Готовые_статьи/.

## Данные по источникам (проверено)

- MOEX ISS: `https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities/{T}.json` — цена, капитализация; history — цены закрытия на дату; капитализация_ист = цена × (кап.тек / цена.тек).
- Росстат: `https://rosstat.gov.ru/storage/mediabank/uroven_innov_2024.xls` — инновационная активность по субъектам; curl -k (битый SSL); лист 2, колонки-годы; методология ломается в 2017 (3-я → 4-я редакция Осло) — брать сопоставимый период.
- БФО ФНС (bo.nalog.ru) — без токена пусто, не тратить время; активы компаний — через открытые агрегаторы (investemika МСФО, cbonds РСБУ) или пресс-релизы; smart-lab блокирует извлечение.
- Пресс-релизы компаний (etalongroup.ru) извлекаются полностью — там выручка/EBITDA/эскроу, но не всегда активы.

## Pitfalls

- Событие в будущем (DiD на предстоящее изменение политики): статья =
  дизайн + базовая линия + гипотезы; окно ажиотажа (anticipation) —
  исключать из выборки или event-study.
- Анонсированные, но не утверждённые параметры политики — помечать
  «обсуждаемый сценарий», не выдавать за факт.
- Числа из источников пересчитывать (платёж 6→10%: 38,7→54,5 тыс. —
  в источнике указано «до 10%», не «до 12%»; ошибка при переносе
  ловится пересчётом аннуитета).
- Экспертные оценки дефицита (500 тыс. — 1 млн) несопоставимы по
  методике — приводить диапазон с источником, не усреднять.
- Статьи-продолжения: опираться на полный текст исходной статьи
  (папка кейса Статьи_txt/) — алгоритм, данные апробации, ограничения.
