# Промпт профилирования автора (темы → скилы → качество → направления)

Готовый промпт для оценки научного профиля исследователя по его
публикациям. Запускать с полными текстами статей (или библиографией)
в качестве входных материалов. Полный пример использования —
кейс Устинова А.Э. (15.08.2026): профиль + ТРИЗ-анализ скилов.

## Промпт (адаптировать имя/пути)

```
ПРОМПТ: АНАЛИЗ НАУЧНОГО ПРОФИЛЯ АВТОРА ПО ПУБЛИКАЦИЯМ

Роль: наукометрический аналитик. Перед тобой материалы публикаций
автора: полные тексты и/или библиографические записи.

ВХОДНЫЕ МАТЕРИАЛЫ: <пути к файлам или тексты>

ЭТАП 1. ТЕМАТИЧЕСКАЯ ИНВЕНТАРИЗАЦИЯ
Для каждой публикации — 2-4 темы (устойчивые конструкты). Таблица:
публикация (год) -> темы. Затем кластеры-направления с частотой.

ЭТАП 2. ОЦЕНКА НАУЧНЫХ СКИЛОВ
По текстам — какими методами РЕАЛЬНО владеет (по применению, не по
упоминанию): уровень базовый/рабочий/продвинутый + обоснование
(одна формула vs построенная и проверенная модель).

ЭТАП 3. ОЦЕНКА КАЧЕСТВА
- уровень журналов (ВАК/РИНЦ/Scopus);
- глубина (обзор vs эмпирика с моделью);
- новизна (заявлена vs подтверждена);
- паттерны (коллективность, первое авторство, самоцитирование);
- динамика по годам.

ЭТАП 4. НАПРАВЛЕНИЯ
3-5 магистральных направлений; где автор в ядре, где периферийный
участник; эволюция тематики по годам.

ЭТАП 5. ИТОГОВЫЙ ПРОФИЛЬ
Компактная таблица + 5-7 строк вывода («автор силён в X, слаб в Y»).

ПРАВИЛА
1. Каждая оценка — с привязкой к публикации (название/год).
2. Факты отделять от оценок.
3. Недостаточно данных — помечать, не додумывать.
4. Уровень скила = глубина применения, не факт упоминания.
5. Итог на русском, пригоден для отчёта без доработки.
```

## ТРИЗ-анализ скилов (следующий слой)

После профиля — ТРИЗ-разбор «что есть / чего не хватает / что добавить»:
1. Верификация посылок (каждое число профиля — с источником).
2. Противоречия: ТП «поток публикаций vs собственная идентичность»
   (первое авторство < 20% — ведомый соавтор), «широта тем vs глубина»,
   «строгость vs методологический арсенал».
3. Матрица 39x39: пары (39/29), (36/39), (9/29) -> приёмы 10, 28, 1,
   13, 17, 24, 3, 25, 26.
4. Веполь: В1 (автор) <- П (задачи группы) <- В2 (коллаборация) —
   неполный, нет В3 (собственная линия); достройка + второе поле.
5. S-кривая: насыщение при повторяемости тем -> законы 7 (микроуровень:
   ML/панели) и 6 (надсистема: методологическое ядро).
6. Что добавить: конкретные методы по темам автора, с приоритетами.
